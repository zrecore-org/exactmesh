# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is incorporated here by reference.
In short: be respectful, assume good faith, accept criticism of work (not of people) gracefully, and do not harass anyone. Harassment, discriminatory language and personal attacks are not acceptable
in issues, pull requests, reviews or any other project space.

**Enforcement.** Report unacceptable behaviour privately to the maintainers through GitHub (a private message to a maintainer of `zrecore-org`, or a private security advisory if nothing else fits;
a dedicated contact address will be added here before the repository is made public). Maintainers will review reports promptly and fairly, keep the reporter's identity confidential, and may
remove content, warn, or block participants as set out in the Covenant's enforcement guidelines.

This text is a short reference, not a replacement for the Covenant; where they differ the Covenant applies.
